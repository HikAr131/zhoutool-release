# 粥小工具

三角洲行动的免费小工具：局内地图、唐吉收集、自动钓鱼、倒子弹推荐。

下载最新版：[zhoutool.exe](https://github.com/HikAr131/zhoutool-release/releases/latest/download/zhoutool.exe)（这个地址永远指向最新版）。放到任意文件夹直接运行，不用安装；程序会自动检查更新。

首次运行时，如果这台电脑缺少 Microsoft Edge WebView2 Runtime，会自动打开微软安装程序。安装需要联网，装好后会继续打开粥小工具。

这个软件免费公开分享，不出售。如果你是花钱买到的，那是被人倒卖了——找卖家退款，也欢迎告诉作者。

遇到问题：在粥小工具侧栏打开「反馈问题」，写一句遇到的问题后，再打开反馈页提交到本仓库的 [Issues](https://github.com/HikAr131/zhoutool-release/issues)。提交的内容会公开显示，请不要填写密码、联系方式或其他个人信息。

本仓库只放发布文件（Releases）与自动更新用的清单 `update.json`，不含源码。
