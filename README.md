下载最新版：[zhoutool.exe](https://github.com/HikAr131/zhoutool-release/releases/latest/download/zhoutool.exe)（这个地址永远指向最新版）。放到任意文件夹直接运行，不用安装；程序会自动检查更新。

这个软件免费公开分享，不出售。如果你是花钱买到的，那是被人倒卖了——找卖家退款，也欢迎告诉作者。
